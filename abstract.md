Ниже привожу **сформулированный абстрактный синтаксис** для языка L1 в том же стиле, что и в примере из исходных данных. Я исхожу из того, что программа в L1 — это набор определений функций; в языке есть примитивные и массивные типы, выражения, а также девять видов операторов: объявление, присваивание, вызов функции, выбор, два вида цикла с предусловием, цикл с постусловием, `return` и `assert`. 

Сразу отмечу важный момент: это именно **абстрактный** синтаксис, поэтому в него не включаются комментарии, скобки, точки с запятой, точная форма записи строковых секций, запись оснований системы счисления и другие детали конкретного синтаксиса. В AST остаются только смысловые сущности программы. Формы `if ... elsif ... else ... end` я нормализую в список ветвей с условиями и необязательную ветвь `else`, а тела функций, условий и циклов представляю как **списки операторов**, потому что в описании L1 они именно так и задаются.

## Абстрактный синтаксис L1

Программа состоит из нуля или более определений функций:

```text
Program → Function*
```

Определение функции состоит из имени, списка формальных параметров, необязательного типа результата и тела:

```text
Function → FuncName Parameters ReturnType? Statements
```

Формальные параметры — это ноль или более параметров:

```text
Parameters → Parameter*
```

Параметр состоит из имени и типа:

```text
Parameter → VarName Type
```

Тип либо примитивный, либо массивный:

```text
Type → int | char | bool | ArrayType
ArrayType → Type
```

Пояснение. В конкретном синтаксисе массивность задаётся постфиксным словом `array`, поэтому в абстрактном синтаксисе удобно считать массивный тип рекурсивным типом над другим типом. Это естественно отражает конструкции вида `int array` и `char array array`. 

Последовательность операторов — это ноль или более операторов:

```text
Statements → Statement*
```

Оператор может быть одним из девяти предусмотренных в языке видов:

```text
Statement → DeclStatement
          | AssignStatement
          | CallStatement
          | IfStatement
          | WhileStatement
          | ForStatement
          | DoWhileStatement
          | ReturnStatement
          | AssertStatement
```

Пояснение. Отдельного узла вида `begin ... end`, как в паскалеподобном примере, здесь не нужно, потому что в L1 тела функций, ветвей и циклов сами по себе уже являются последовательностями операторов. 

### Операторы

Оператор объявления задаёт тип и список объявляемых переменных, каждая из которых может иметь инициализацию:

```text
DeclStatement → Type DeclItem+
DeclItem → VarName Expr?
```

Оператор присваивания связывает изменяемую ячейку с новым значением:

```text
AssignStatement → LValue Expr
```

Оператор вызова функции как отдельный оператор:

```text
CallStatement → FuncCallExpr
```

Оператор выбора содержит одну или более условных ветвей и необязательную ветвь `else`:

```text
IfStatement → Branch+ ElseBranch?
Branch → Expr Statements
ElseBranch → Statements
```

Цикл `while` содержит условие и тело:

```text
WhileStatement → Expr Statements
```

Цикл `for` содержит переменную цикла, начальное значение, конечное значение, необязательный шаг и тело:

```text
ForStatement → ForTarget Expr Expr Expr? Statements
ForTarget → VarName | TypedVar
TypedVar → VarName Type
```

Цикл с постусловием состоит из тела и условия:

```text
DoWhileStatement → Statements Expr
```

Оператор завершения функции содержит необязательное возвращаемое выражение:

```text
ReturnStatement → Expr?
```

Оператор-предупреждение содержит проверяемое условие:

```text
AssertStatement → Expr
```

Пояснение. Для `for` я специально выделяю `ForTarget`, потому что в L1 переменная цикла может либо уже существовать, либо объявляться прямо в заголовке цикла. Для `return` выражение делаю необязательным, так как в языке есть и функции, возвращающие значение, и функции без возвращаемого значения. 

### Выражения

Выражение может быть переменной, константой, вызовом функции, обращением к элементу массива, выделением массива, унарной или бинарной операцией:

```text
Expr → VariableExpr
     | ConstExpr
     | FuncCallExpr
     | ArrayAccessExpr
     | NewArrayExpr
     | UnOpExpr
     | BinOpExpr
```

Переменная определяется именем:

```text
VariableExpr → VarName
```

Константа может быть целочисленной, символьной, строковой, булевой или ссылочной `NULL`:

```text
ConstExpr → IntConst
          | CharConst
          | StringConst
          | BoolConst
          | NullConst
```

Вызов функции состоит из имени и списка фактических параметров:

```text
FuncCallExpr → FuncName Arguments
Arguments → Expr*
```

Доступ к элементу массива состоит из выражения-массива и выражения-индекса:

```text
ArrayAccessExpr → Expr Expr
```

Выделение памяти под массив состоит из типа элементов и выражения размера:

```text
NewArrayExpr → Type Expr
```

Унарная операция:

```text
UnOpExpr → UnOp Expr
UnOp → - | not
```

Бинарная операция:

```text
BinOpExpr → Expr BinOp Expr
BinOp → **
      | * | / | mod
      | + | -
      | = | <> | < | > | <= | >=
      | and | or | xor
```

Пояснение. Скобки в абстрактный синтаксис не входят, потому что они нужны только для управления порядком разбора во входном тексте. Аналогично, приоритеты и ассоциативность операций учитываются в конкретной грамматике, но в AST все бинарные и унарные операции удобно представлять единообразными узлами. Сюда же естественно попадают `new T[x]`, вызов функции и индексирование массива, так как в описании языка они входят именно в систему выражений. 

### Изменяемые ячейки

Для присваивания полезно отдельно выделить выражения, которые могут стоять слева от `:=`:

```text
LValue → VariableExpr
       | ArrayAccessExpr
```

Пояснение. Это абстракция именно для дерева. Семантическое ограничение, что слева должна быть **изменяемая** ячейка, а идентификаторы с заглавной буквы неизменяемы, проверяется уже дополнительно. Однако на уровне AST такое разделение удобно, потому что оно сразу отличает обычное выражение от потенциальной левой части присваивания. 

## Текст с пояснениями в стиле примера

Программа в языке L1 представляет собой последовательность определений функций:

```text
Program → Function*
```

Определение функции состоит из имени функции, списка формальных параметров, необязательного типа возвращаемого значения и тела:

```text
Function → FuncName Parameters ReturnType? Statements
```

Тип может быть примитивным или массивным:

```text
Type → int | char | bool | ArrayType
ArrayType → Type
```

Оператором языка является объявление, присваивание, вызов функции, выбор, цикл с предусловием, цикл `for`, цикл с постусловием, завершение функции или предупреждение:

```text
Statement → DeclStatement
          | AssignStatement
          | CallStatement
          | IfStatement
          | WhileStatement
          | ForStatement
          | DoWhileStatement
          | ReturnStatement
          | AssertStatement
```

Выражение может быть переменной, константой, вызовом функции, выделением массива, обращением к элементу массива, унарной или бинарной операцией:

```text
Expr → VariableExpr
     | ConstExpr
     | FuncCallExpr
     | ArrayAccessExpr
     | NewArrayExpr
     | UnOpExpr
     | BinOpExpr
```
